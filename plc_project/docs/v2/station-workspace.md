# V2 工位工作台

在 V2 统一工程工作台中，项目由硬件组态、工位和项目流程组成。工位流程负责设备动作，项目流程负责串行或并行调度工位。步骤、逻辑图、时序和 AF 生成共用版本化的 `station_design`。

## 创建或打开项目

1. 打开 `http://localhost:5173/#/v2`，选择「新建 V2 工程」。
2. 在「硬件组态」中填写 PLC CPU 和 I/O 模块，登记输入、输出信号及其地址。
3. 在「工位清单」中创建工位，名称可自定义。点击「进入工位」打开设备清单。
4. 已有项目可以用项目 ID 继续编辑。通过「导入 AF 工程」可以检查并导入 AF 画布 JSON 或包含 `af-canvas.json` 的 AF 源码 ZIP。文件须符合当前 AF Profile 和 `af-station-canvas/1` 格式，确认后会创建独立的可编辑项目。在配置了归档导入能力的环境中，单独的 `.zap19` 可检查程序块和 AF 角色，继续编辑需要配套的 AF 画布。

## 添加设备和编排动作

- 在工位内按气动执行、电动执行、夹持与搬运、检测与识别、外部设备筛选设备，也可按名称搜索。设备库包含 31 种设备，其中 16 种提供可生成 AF 的驱动。
- 展开「I/O 绑定与参数」可为设备自定义名称、绑定信号并设置默认动作超时。常用预设包含气缸伸出和缩回、电机启停、夹爪夹紧和松开、伺服回原位和到工作位。预设会带入设备命令、完成反馈和超时。
- 点击设备动作旁的「＋」可以把动作加入流程。在「动作步骤」中可以调整顺序、合并并行动作、关联反馈、设置超时去向或加入定时等待。
- 点击「描述工位流程」，输入中文描述，选择「预览修改」后核对目标设备、动作顺序和完成条件，再「应用修改」。反馈无法确定时，步骤会标记「反馈待关联」，可选择工位中的输入信号及其期望值。预览可能先保存当前的手动草稿，提案本身需应用才写入。
- 支持 AF 生成的伺服轴由外部定位控制器提供预置位置和数字 I/O 握手。标为「待配套驱动」的 TIA 工艺对象、总线电机、视觉或机器人等设备可先加入草稿，项目发布需要相应驱动。

以下用气动夹爪、伺服轴和光电传感器演示。设备实例名分别设为「夹爪 A」「横移伺服」「工件到位」。

> 工件到位后，夹爪 A 夹紧。夹紧到位后，横移伺服移动到工作位。伺服回原位，再松开夹爪。夹紧等待超过 2 秒就进入故障分支。

应用后可以继续输入「在松开前插入等待 300 ms」或「把夹紧的超时改为 2.5 秒」，也可在「动作步骤」中手动修改。如果已有流程需要整体重排，可用「重新生成工位流程」开头，预览时复核将被替换的步骤和连线。

## 检查时序与生成 AF

1. 在「工位逻辑」查看动作、等待和分支。用「工位时序」运行正常反馈、反馈超时等离线场景，场景会提供模拟反馈。项目层的「项目流程」和「项目时序」用于验证工位间的调度。
2. 在「AF 生成」点击「生成 SCL 预览」。工程检查包括 CPU、模块、I/O 绑定、待关联反馈及连线。SCL 预览可以沿源码映射定位回画布。同一设备类型生成一份驱动 FB，工位中的各设备分别实例化。
3. 填写确认人并「确认此修订」。下载的 AF 源码 ZIP 包含 SCL、清单、源码映射和 AF 画布。源码包绑定已确认的修订，可用于后续导入。
4. 需要原生归档时，在硬件组态填写 CPU 完整目录标识，确认当前修订后选择「V19 编译并归档」。任务在独立 TIA 工程中执行。状态达到 `NATIVE_ARCHIVED` 并通过重新打开验证后，工作台会提供 `.zap19` 下载。

## 接口与验收

| 操作 | V2 接口 |
|---|---|
| 获取设备规格、动作与完成反馈 | `GET /api/v2/station-catalog` |
| 生成自然语言提案 | `POST /api/v2/projects/{project_id}/intent`，可传 `context_slice.station_id` 和 `context_slice.node_id` |
| 应用草稿修改 | `POST /api/v2/projects/{project_id}/patches`，使用 `set_station_design` 和当前 `base_revision` |
| 运行工位或项目离线时序 | `POST /api/v2/projects/{project_id}/simulate`，工位级传入 `station_id` |
| 检查并导入 AF 画布 | `POST /api/v2/station-import`，检查后通过 `confirm=true` 创建项目 |
| 下载已确认修订的 AF 源码 | `GET /api/v2/projects/{project_id}/source-package`，使用已批准的 `changeset_id` |
| 为当前已确认修订创建 V19 任务 | `POST /api/v2/projects/{project_id}/station-deliveries` |

桌面与移动端浏览器已验证设备添加、自然语言预览、手动绑定反馈、步骤修改与同步。夹爪、伺服和光电传感器的验收工程通过 TIA V19 编译（0 个错误、14 个警告），并验证了 `.zap19` 的重新打开和下载。该验收覆盖工程生成与归档，现场设备仍需联调。
