# PLC_chat 双层画布编排开发计划

更新日期 2026-11-17。依据 2026-11-16 会话中已确认的需求及五阶段开发顺序整理，并记录交接后的验证结果。

## 产品目标

V2 工作台以画布作为工程主编辑器。打开项目显示工位节点和调度关系，双击工位进入设备动作画布，沿顶部路径返回项目。用户可以拖入节点、绘制连线、配置节点，也可以用中文生成或修改当前画布。已确认的 `station_design` 同时用于离线时序、AF 源码和 TIA 工程生成。

## 已确认需求

### 项目与工位两层编排

| 层级 | 节点 | 执行含义 |
|---|---|---|
| 项目画布 | 工位、开始、结束、判断、并行分支、全部汇合 | 工位的顺序、并行、完成交接和故障去向 |
| 工位画布 | 设备动作、反馈等待、定时等待、判断、并行分支、全部汇合、完成、故障 | 设备执行动作、完成反馈、等待时间、超时和互锁处理 |

- 新建工程配置 CPU、I/O 模块和信号后进入项目画布，工位支持自定义名称。
- 节点库可搜索、按类别浏览，节点可拖入画布，也可点击添加。
- 节点提供明确的运行入口和完成、超时、故障、条件真假等出口，用户可从出口拉线到目标入口。
- 出口旁的「＋」可以创建并连接下一节点，连线可以选中、删除和改接。
- 节点布局随草稿保存。移动节点更新布局，连线表达执行关系。
- 双击工位或点击「打开工位」进入子画布，顶部路径返回项目。
- 并行节点分别启动各分支，汇合节点等待所关联分支完成。
- AF 画布 JSON 和带 `af-canvas.json` 的源码 ZIP 支持回导。单独原生归档的编辑能力取决于配套画布定义。

### 设备实例与动作复用

- 复用已有设备目录、动作预设、默认反馈和超时。
- 首次从模板拖入设备时创建实例，后续从「已有设备」拖入该实例的其它动作。
- 「夹爪 A · 夹紧」和「夹爪 A · 松开」分别对应流程节点，共用设备实例、I/O 绑定及驱动实例。
- 节点检查器配置动作、完成反馈、超时、设备绑定和运行许可。
- 同类型设备共享驱动定义，各台设备分别实例化。
- 无法关联的反馈在对应节点标记待补齐，检查入口可定位到问题节点。

### 互锁

| 规则 | 配置与表现 | 验收结果要求 |
|---|---|---|
| 设备内部互斥 | 气缸伸出和缩回由驱动内置互斥，同一设备并行冲突定位到动作节点 | 相反请求发生时双向输出不能同时有效，并报告冲突 |
| 启动许可 | 在动作上选择设备反馈，配置条件不满足时等待或进入异常出口 | 许可满足后启动，等待时显示阻塞条件 |
| 持续许可 | 动作运行期间持续检查已配置反馈 | 反馈丢失时撤销动作请求，沿互锁失效出口处理 |
| 图上表达 | 顺序连线为实线，运行许可为虚线 | 连线和离线时序能够定位对应条件与节点 |

### 中文与手动编辑协同

- 项目层描述工位调度，工位层描述设备动作和互锁。
- 提案在当前画布高亮新增、修改和移除内容，确认后应用。
- 支持先手动画图、再用中文补充、再手动修改连线。
- 手工草稿成为后续提案的输入，修订冲突需要重新核对提案。
- 支持撤销与重做，保存和重开后流程及布局一致。

## 开发顺序与验收

| 阶段 | 交付内容 | 阶段验收 |
|---|---|---|
| 1. 项目主画布 | 默认画布入口、工位拖入、端口拉线、分支、下钻、布局持久化、旧流程兼容 | 从空项目创建并连接两个工位，进入子画布后返回，重开恢复布局与连线 |
| 2. 工位设备画布 | 设备模板和已有动作、完成反馈、超时、等待、判断、并行和汇合 | 纯拖拽完成「工件到位 → 夹紧 → 伺服定位 → 同一夹爪松开」，连接超时支路 |
| 3. 互锁与离线时序 | 驱动互斥、工艺许可、冲突定位、阻塞和失效场景 | 气缸相反并行请求能定位冲突，夹紧许可不足时伺服等待，持续反馈丢失进入异常路径 |
| 4. 中文画布编辑 | 当前上下文提案、差异预览、应用、撤销、待关联反馈、修订冲突 | 手动与中文交替修改后保存，重开后结果一致 |
| 5. AF 生成与回归 | 统一流程生成时序、SCL、源码映射和源码包，接入 V19 编译归档 | 正常、超时和互锁场景通过，源码包可回导，原生归档可重新打开并下载 |

## 首个端到端验收工程

采用两个工位，在项目层验证并行调度和完成汇合。工位 A 包含夹爪、横移伺服、气缸，验证夹紧后的许可、动作并行、气缸伸出后缩回及异常分支。工位 B 验证独立动作和反馈等待。

现有验收工程为 `prj_d2b5eb84d919`，V19 任务为 `job_fba2b462325947c0`。

1. 在空画布拖入首个工位，确认节点保留鼠标落点，视口保持稳定。
2. 在另一处拖入第二工位，确认两个节点的端口可分别操作。
3. 从完成口拉到目标入口，核对连线类型和检查器，再改接并删除连线。
4. 双击工位下钻，在工位画布拖入设备和同实例的其它动作，连接完成与超时出口。
5. 配置夹紧反馈许可，检查实线与虚线表达，运行正常、反馈超时、启动阻塞和持续许可丢失场景。
6. 在手动画布上预览并应用中文修改，执行撤销、重做及保存，重开核对布局与连线。
7. 生成 SCL 并核对互斥、持续许可和源码映射，检查对应修订的源码与原生归档。
